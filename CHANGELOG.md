# Changelog

## 1.5.1 — 2026-10-23

- Improved campaign embedding using URLs and Embed IDs.
- Improved display conditions for pages, posts, and archives.
- Fixed duplicate campaign placements in some layouts.
- Fixed campaigns continuously growing when embedded, including editor previews.
- Improved keyboard accessibility and the display-condition controls.
- Strengthened embed security and handling of page URL parameters.
- Improved translation support.
- Requires WordPress 6.6 or later and PHP 7.4 or later.

## 1.5.0 — 2025-11-11

- Added conditional rules to display campaigns across multiple pages or site-wide.
- The Woorise block and shortcode now use Embed IDs.
- Updated iframe resizing.

## 1.4.0 — 2025-02-12

- Fixed conflicts with URL parameters in campaign previews.
- Updated iframe resizing.

For earlier versions, see the [full Woorise plugin changelog](https://woorise.com/help/wordpress#woorise-plugin-changelog).
